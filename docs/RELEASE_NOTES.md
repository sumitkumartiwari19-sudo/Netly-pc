## Netly for PC

A fast, good-looking YouTube downloader and player for Windows.

**Highlights**
- Search, play and download videos and music; quality from 144p up to 4K, plus MP3, M4A and Opus
- Built-in player with full screen, music mode, speed, queue and mini player
- Download queue with pause, resume, retry; library of finished files with previews
- Light and dark themes, English and हिन्दी, smooth mode for older PCs
- Engine updates itself; backup route when YouTube blocks a request
- In-app update check, developer info, feedback and report-a-problem links
- No account, no ads, no tracking

**Install**
1. Download `Netly-<version>.exe` below and run it.
2. If Windows shows "Windows protected your PC": **More info → Run anyway** (the app is not code-signed yet).
3. Optional: check the file against `SHA256SUMS.txt` (`Get-FileHash .\Netly-<version>.exe -Algorithm SHA256`).

Needs Windows 10 (1809+) or Windows 11, 64-bit. Netly is not affiliated with YouTube or Google; save only content you have the right to.
